# Visual design system

Use the near-black grid, matte graphite surfaces and Inter typography established by Behind The Tech. Attach cyan dashed routes to real object ports. Purple signals processing. Green, amber and red signal outcomes. Keep captions clear of diagram geometry and reserve space for labels at portrait size. Avoid enclosing panels when the objects can explain the mechanism on the shared grid.

Use the runtime palette and geometry rules listed in the production contract. The golden reference illustrates proportion, density and visual hierarchy.
